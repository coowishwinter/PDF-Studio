# 简页 · PDF 编辑器 (PDF Studio)

**简页**是一款永久免费、纯本地的 PDF 编辑器（支持在线预览、**PDF 可视化编辑**、**PDF 合并**、**PDF 拆分提取**、**高清打印与批量打印**、高清批量转图片、文字提取）。所有的 PDF 解密、页面渲染、文档合成、拆分、编辑及打印排版工作**百分之百运行在用户的浏览器本地沙盒中**，不经过任何后台服务器，确保极为敏感的文档隐私性与安全性。

## 免费与隐私

- **永久免费**：编辑、合并、拆分、打印、转图、文字提取全部功能免费，无会员、无次数限制、无隐藏收费。
- **纯本地处理**：文件只在你的浏览器中打开和处理，绝不上传服务器；无账号、不收集文档内容。
- **隐私优先**：适合合同、证件、财务资料等敏感文档；渲染、合成与导出均在本地内存完成。

## ✨ 核心特性

- 🔒 **极端安全与私密**：无后台上传，没有流量外流。
- ✏️ **PDF 可视化编辑**：
  - **内容标注**：在页面上直接插入文字（支持中文/emoji、字号、颜色、加粗、不透明度）、图片/手写签名、高亮、矩形边框与涂白遮挡，元素可自由拖动、缩放、删除，支持撤销/重做。
  - **图片编辑**：图片/签名插入后可自由拖动移动（方向键微调）、右下角拖拽缩放、顶部圆形手柄任意旋转（自动吸附 90°，按住 Shift 按 15° 吸附）。选中图片后可直接点左上角剪刀或双击打开裁剪，裁剪弹窗支持拖动框选、四角/四边手柄调整、左/上/右/下百分比精确输入，应用后自动保持宽高比。
  - **剪裁 PDF 原有图片**：工具栏选择「剪裁原图」，在页面上框选 PDF 中原有的图片/内容，自动生成一个可编辑图片图层（用同色覆盖原区域），之后可继续裁剪、旋转、移动。选中任意元素后，可直接拖拽到其他页面（跨页平移），也可用右侧「所在页」下拉精确切换。注意：框选区域会被栅格化为图片，区域内的文字也会一并变成图片。
  - **页面操作**：逐页左/右旋转、删除、上移/下移排序、插入空白页。
  - **批量水印与页码**：一键为所有页面添加斜向水印、页码（支持 `{n}` / `{total}` 占位符、位置与字号调整）。
  - **一键导出**：自动保留原始页面旋转角度与顺序，编辑内容合成后导出新 PDF；文字以高分辨率栅格形式嵌入，完全避免中文字体缺失问题。
- 📑 **多文档 PDF 合并**：支持将多个 PDF 电子文档任意调整排序合并为一个新文档，支持为每个文档自定义提取合并页码范围，并可实时计算总页数及一键下载或载入预览。
- ✂️ **PDF 智能拆分与提取**：
  - **自定义页码提取**：支持输入页码范围（如 `1-3, 5`）或直接点击页面缩略图可视化点选，支持全选/奇偶数页快捷筛选并导出新 PDF。
  - **单页拆分归档**：将文档每页单独拆解为一个独立 PDF，并打包为 `.zip` 压缩包批量下载。
  - **固定间隔分卷**：按指定间隔（如每 2 页、每 5 页）自动分卷切分并打包为 ZIP。
- 🖨️ **高清打印与批量打印**：
  - **单文档打印**：支持全页或自定义页码范围打印，可直接调起操作系统打印机对话框，或导出打印专用高清 PDF。
  - **多文档批量打印**：支持一次勾选多个文档、自由调整打印次序与各文档打印页码，一键调起浏览器批量打印队列，免去逐个打开打印的繁琐流程。
- 🖼️ **批量无损转图片**：支持一键将 PDF 所有页面批量导出为 PNG / JPEG / WEBP 图像并打包为 `.zip` 压缩归档下载。
- ⚙️ **自定义输出分辨率**：支持 `1x` (标准流畅)、`1.5x` (中等清晰)、`2x` (超高清，推荐)、`3x` (极限细腻打印级) 画质。
- 📝 **智能文本布局提取**：一键解析排版内容并提取干净的文字段落，支持一键快捷复制。
- 🌗 **昼夜护眼双色主题**：配备设计雅致的浅色（Light）与深色（Dark）两种极简极客界面。
- 📁 **本地拖拽与多文档管理**：支持侧边栏多任务快速切换，拖拽 PDF 文件即刻开启编辑。

## 🐳 Docker 及 YAML 部署说明

本软件已被完全容器化。为了方便一键部署，我们在项目根目录下为您编写了 `Dockerfile` 及 `docker-compose.yml` (YAML) 配置文件。

### 方式 A：使用 Docker Compose 一键启动（推荐 💡）

在包含 `docker-compose.yml` 的目录下，只需执行一行命令，系统将自动构建镜像并启动服务：

```bash
docker compose up -d
```

- 默认容器端口映射到了宿主机的 **`8080`** 端口上。
- 您可以通过打开浏览器并访问 `http://localhost:8080` 开始使用。
- 若要停止该服务，轻敲 `docker compose down` 即可。

### 方式 B：使用标准 Docker 命令
如果您不想使用 Compose，也可以通过以下传统的两步法手动构建并运行：

1. **构建官方物理镜像**：
   ```bash
   docker build -t pdf-studio:latest .
   ```

2. **启动 Docker 容器**：
   ```bash
   docker run -d -p 8080:80 --name pdf-studio-app pdf-studio:latest
   ```

如果您需要进行二次开发或本地启动：

```bash

npm install
```

## 💡 性能与内存提示
- 所有图片的高分辨率和打印页面是通过 PDF.js / pdf-lib 计算渲染的。遇到上百页的超大文档时，建议选择推荐的 `2x` 清晰度，速度、打印锐利度与内存占用达到最佳平衡。
